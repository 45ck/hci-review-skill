# Standards and graphics component contract

The former **Developer components** section is now **Standards**. Its scope includes business, systems and other OMG specifications, alongside the separately attributed LMU UWE profile. The `/developer` package entry remains a compatibility export.

Read the current [Standards, graphics and shared-canvas contract](standards-components.md), [versioned OMG coverage registry](omg-coverage.md), and [worked exploration model](../models/developer-model-exploration.md).

All custom components remain **Unvalidated**: a human UI/UX team has not reviewed or approved them. The **SDK foundation** label records Vercel UI SDK provenance and does not validate Quantive's adaptations.
